### Guidelines

Each project is different and needs individual treatment.
The guidelines establish a set of principles about the data
organisation, how to encode and render content, search options, additional
resources that are specific to your project and turn them into
a sustainable project setup. However the guidelines can evolve over time to allow
flexibility for future enhancements.

### Transcription

Following the guidelines data are transcribed into a XML representation like TEI to lay
the fundament for enrichment. The data source can be MS Word, edited with third-party editors like Oxygen
or VSCode or provided as third-party raw transcriptions.

### Enrichment

Enrichment turns data into information by adding semantics. It's the most time consuming
task during project lifetime and requires optimal tool support. With our web annotation module
annotations can be made right in the browser. Custom annotations can be attached anywhere
and optionally link to authorities. With batched annotations repetitive encoding tasks 
are eliminated applying similar properties to
a set of found occurrences. Machine learning support handles the bulk of entity 
recognition to quickly identify people, places and dates etc.
