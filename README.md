## Local Development

1. Install [Hugo](https://gohugo.io/getting-started/quick-start/)


2. Clone the project
```shell 
git clone git@gitlab.existsolutions.com:jinntec/homepage.git
```

3. Start a local hugo server with
```shell 
hugo server
```
