  title: "What We Offer"
  block:
  - title: "Encoding guidelines, data structures etc."
    content: "This is often neglected. It is important though to be explicit about the encoding principles, TEI subset etc. before you start transcribing. This includes writing an ODD from which a schema and project documentation can be generated. We can also suggest an organization for your data files: encoded source documents, authority files (such as lists of persons, places or bibliography), image resources, binary files etc. Consulting with us in this phase will also help to avoid costs later as we can establish a data structure tailored to the specific requirements and research questions of a project.
"

  - title: "Transcription of the manuscript"
    content: "Jinntec supports editions with different approaches depending on the customers requirements:
      * create a Word template and customize the Word import accordingly to ensure high-quality TEI aligned with the established encoding guidelines
      * XML-editing workflows based on oXygen or VSCode.
      * or start with an HTR engine like transkribus for acquiring the raw transcription
    All cases should include proper version management based on git."
    
  - title: "Semantic and analytic enrichment"
    content: "This is usually the most time consuming task in a project. TEI Publisher's web annotations eliminate the tedious and repetitive work of encoding entities in the XML, so editors can concentrate on more interesting research instead of having to enter thousands of TEI elements for semantic and analytic markup. "
    
  - title: "Metadata entry"
    content: "Entering the necessary metadata about a document is often a separate workflow task. Knowing where exactly to put which information in the TEI header can be challenging at least: there are probably as many opinions as there are TEI users. We can free you from the burden by designing an input form which is customized for your requirements."

  - title: "Producing a Digital Edition"
    content: "This is what we focused on so far, i.e.
      * ODD-based transforms
      * custom indexes
      * search/filtering/facets
      * page templates
      * custom styling
      * static content"
  - title: "Print Publication"
    content: "Note: heavily neglected by us:
        * the print examples in TEI Publisher are not really appealing
        * documentation for print output is lacking
        * there's no tutorial/extended description about how to generate high-quality LaTeX

        But: we are able to produce PDF which can be directly passed to the printing press, see SSRQ or Buddhist Stone Sutras. And: we know how to automate the print production process to avoid any labour intensive, manual typesetting and thus reduce costs tremendously."
